# Sentiment Analysis using Transformer Pipeline

## Description

This project performs sentiment analysis using the Hugging Face Transformer Pipeline. It analyzes user-provided text and classifies it as **Positive** or **Negative** along with a confidence score.

## Technologies Used

* Python
* Hugging Face Transformers
* PyTorch

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python sentiment_analysis.py
```

Enter a sentence when prompted.

## Example

**Input:**

```text
I really love this product.
```

**Output:**

```text
Sentiment: POSITIVE
Confidence Score: 0.99
```
